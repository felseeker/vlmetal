# Настройка Yandex Cloud для vlmetal.ru

## Зачем
Персональные данные (имя, телефон) должны храниться на серверах в РФ (ФЗ-152).
Yandex Cloud — российская платформа, бесплатно до 1 млн вызовов/мес.

## Шаг 1: Регистрация в Yandex Cloud

1. Зайди на https://cloud.yandex.ru
2. Авторизуйся через Яндекс ID
3. Создай облачную платформу (первые 30 дней бесплатно)
4. Привяжи банковскую карту (для активации, списаний не будет в рамках бесплатного тарифа)

## Шаг 2: Создание облачной функции

1. В консоли Yandex Cloud → **Облачные функции**
2. Нажми **Создать функцию**
3. Название: `vlmetal-submit`
4. Рuntime: **Node.js 18**
5. Загрузи файлы из папки `yandex-cloud/submit/`
6. В поле "Точка входа" укажи: `index.handler`

## Шаг 3: Переменные окружения

В настройках функции добавь переменные:

| Переменная | Описание | Как получить |
|------------|----------|--------------|
| `YANDEX_SPREADSHEET_ID` | ID таблицы Яндекс | Создать таблицу, скопировать ID из URL |
| `YANDEX_SPREADSHEET_TOKEN` | OAuth токен Яндекс Sheets | https://oauth.yandex.ru → создать приложение → доступ к Yandex Sheets |
| `VK_TOKEN` | Токен VK бота | https://vk.com/dev → создать сообщество → токен сообщества |
| `VK_CHAT_ID` | ID беседы VK | Узнать через @getidsbot в нужной беседе |
| `TG_BOT_TOKEN` | Токен Telegram бота | Уже есть: 8905633150:AAG4qWzLnHsv4R2YBZMzEQtWqJDXHhio3EM |
| `TG_CHAT_ID` | ID чата Telegram | Уже есть: -1003946656029 |
| `TG_THREAD_ID` | ID топика Telegram | Уже есть: 32 |

## Шаг 4: Создание таблицы

1. Зайди на https://docs.yandex.ru
2. Создай новую таблицу
3. В первом листе создай заголовки: **Дата** | **Имя** | **Телефон** | **Сообщение** | **Статус**
4. Скопируй ID таблицы из URL (после `/d/`)

## Шаг 5: Получение OAuth токена

1. Зайди на https://oauth.yandex.ru
2. Создай новое приложение
3. В списке прав выбери: **Яндекс.Диск REST API** и **Яндекс.Таблицы**
4. Скопируй токен

## Шаг 6: Настройка VK бота

1. Зайди в https://vk.com/groups?w=groups_list
2. Создай сообщество (или используй существующее)
3. В настройках сообщества → **Работа с API** → Включи API
4. Создай ключ доступа с правами: **messages**
5. Скопируй токен сообщества
6. Добавь бота в нужную беседу
7. Узнай ID беседы через API или @getidsbot

## Шаг 7: Публикация функции

1. В консоли Yandex Cloud → нажми **Создать версию**
2. Дождись деплоя
3. Скопируй URL функции (выглядит как `https://functions.yandexcloud.net/...`)

## Шаг 8: Обновление сайта

В `index.html` найди строку:
```javascript
fetch('https://vlmetal.vercel.app/api/submit', {
```

Замени на:
```javascript
fetch('https://FUNCTION_URL', {
```

Где `FUNCTION_URL` — URL твоей Yandex Cloud Function.

## Шаг 9: Тестирование

1. Открой сайт
2. Заполни форму
3. Нажми "ОТПРАВИТЬ"
4. Проверь:
   - Яндекс Таблицу — должна появиться строка
   - VK беседу — должно прийти уведомление
   - Telegram — должно прийти "🔔 Новая заявка на сайте!"
