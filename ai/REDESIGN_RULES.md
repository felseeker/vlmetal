# Правила полного редизайна

Документ обязателен перед каждым крупным изменением визуала сайта.

## Цель

Сделать профессиональный современный строительный сайт для ООО «Концепция Строительства», который:

- быстро объясняет два направления бизнеса;
- показывает реальные работы и производственные возможности;
- вызывает доверие к компании и договору с ООО;
- ведёт пользователя к звонку, заявке или бесплатному замеру;
- одинаково хорошо работает на мобильном и десктопе.

## Визуальное направление

- База: современный архитектурно-строительный стиль, без шаблонного «неона», киберпанка и декоративного шума.
- Главная тема: светлая архитектурная тема с графитовым текстом, стальным серым и тёплыми поверхностями.
- Дополнительная тема: тёмная графитовая тема через существующий переключатель.
- Металлоконструкции: оранжевый accent.
- Внутренняя отделка: жёлтый accent.
- Различие направлений только в accent, не в структуре, шрифтах, header, footer или поведении компонентов.
- Фон не должен содержать заметную постоянную сетку, полосы или «швы», мешающие чтению.
- Изображения должны быть главным доказательством результата, а не декоративным фоном с тяжёлыми фильтрами.

## Типографика

- Заголовки: выразительные, но компактные. Не использовать гигантские заголовки, занимающие весь первый экран.
- Desktop H1: ориентир `42-64px`, mobile H1: `32-42px`, корректировать по длине текста.
- Основной текст: `16-19px`, line-height минимум `1.45`.
- Подписи и metadata: `11-14px`, не уменьшать до нечитаемых размеров.
- Не использовать uppercase для длинных абзацев. Uppercase допустим только для коротких labels, кнопок и категорий.
- Не смешивать больше двух семейств шрифтов.

## Layout

- Один общий header на всех страницах.
- Один общий footer на всех страницах.
- Общее меню: Главная, Металлоконструкции, Внутренняя отделка, Примеры работ, О компании, Контакты.
- Страницы направлений имеют одинаковый порядок ключевых блоков: hero, услуги/прайс, доказательства, процесс, отзывы/FAQ, CTA.
- Главная маршрутизирует и формирует доверие, не дублирует полный каталог.
- Портфолио показывает реальные объекты без подмены ценами и рекламными иллюстрациями.
- Секции имеют ясную вертикальную иерархию и не используют чрезмерное количество карточек.
- Максимальная ширина контента: примерно `1200-1280px`.
- Не допускать горизонтального overflow на `375px`.

## CTA и контент

- На каждом экране одна главная CTA и одна вторичная.
- Тексты CTA конкретные: «Получить расчёт», «Заказать бесплатный замер», «Обсудить проект».
- Не обещать интерьерный ремонт по фотографиям тамбуров и входных зон. Использовать честные описания.
- Цены показывать как ориентир и рядом объяснять, что точная смета зависит от замера/ТЗ.
- Не выдумывать кейсы, клиентов, сроки, материалы или фотографии.

## Motion

- Перед написанием анимации обязательно искать официальный паттерн через Motion MCP.
- Использовать Motion для иерархии: reveal, stagger, мягкий hover, смена состояния фильтра.
- Не анимировать каждый элемент одновременно.
- Не использовать бесконечные декоративные анимации, мешающие чтению.
- Для пружин использовать сгенерированные CSS `linear()` кривые, а не случайные `ease`.
- Всегда реализовывать `prefers-reduced-motion: reduce`.
- Не использовать transform, который меняет геометрию соседних элементов или вызывает layout shift.

## Accessibility

- Контраст обычного текста минимум 4.5:1 в обеих темах.
- Focus-visible обязателен для ссылок, кнопок, табов, фильтров и FAQ.
- Touch target интерактивных элементов минимум 44x44px.
- Все формы имеют настоящие labels, статусы отправки имеют `aria-live`.
- Декоративные SVG имеют `aria-hidden="true"`; meaningful images имеют честный alt.
- Автопереключение hero не должно быть единственным способом увидеть контент.

## Контент и CRM

- Портфолио и прайс проектировать как данные, а не как уникальный HTML для каждой позиции.
- Будущие поля: `id`, `title`, `category`, `direction`, `description`, `image`, `images`, `price`, `unit`, `featured`, `alt`.
- HTML остаётся статическим и SEO-доступным.
- CRM подключается через build-time sync, не напрямую из браузера.
- Реальные токены и ключи не добавлять в сайт или документацию.
