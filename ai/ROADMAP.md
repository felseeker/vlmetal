## Фаза 2 — Единая дизайн-система с акцентом по направлению (решено 17.08.2026)

Решение: **одна структура/система компонентов на весь сайт**, различие только в акцентном цвете по направлению — металлоконструкции остаются на оранжевом (`#ff6a00`, текущий `style.css`), внутренняя отделка переходит на жёлтый акцент, но **на той же тёмной индустриальной базе**, что и остальной сайт (не отдельная светлая кремовая тема, как сейчас в `otdelka.css`). ## Фаза 4 — Админ-панель контента: Build-time sync с vlmetal-crm (решено 17.08.2026)

Цель: редактировать прайс-лист и портфолио через уже существующую CRM (`shadcn-admin`), без правки HTML/CSS сайта напрямую. Выбранная архитектура — **build-time sync**: скрипт тянет данные из CRM API и генерирует статичный контент сайта при публикации, а не в рантайме браузера. Это сохраняет SEO (весь текст виден краулеру Яндекса/Google сразу в HTML) и не создаёт зависимости живого сайта от доступности CRM API.

### 4.1 Backend CRM (`vlmetal-crm/yandex-cloud/crm-api`)
- [ ] Расширить ресурс `catalog` полем `unit` (м², м.п., шт, услуга) — нужно для единого формата прайс-листа металла и отделки.
- [ ] Добавить новый ресурс `portfolio` в `ALLOWED` список `crm-api/index.js` (по аналогии с `catalog`): поля `title, category, direction (metall|otdelka), images[], description, date, featured`.
- [ ] Добавить публичный (без JWT) read-only режим для `GET /api/catalog` и `GET /api/portfolio` **только для серверного sync-скрипта**, не для браузера — например, отдельный служебный токен/ключ вместо полного открытия CORS, чтобы не открывать данные всем посетителям сайта напрямую.

### 4.2 Frontend CRM (`shadcn-admin`)
- [ ] Создать `shadcn-admin/src/features/portfolio/` — React-модуль по аналогии с `features/catalog/catalog-page.tsx` (CRUD, загрузка фото через существующий `upload` S3-endpoint, фильтр по категориям/направлению, привязка к `direction: metall|otdelka`).
- [ ] Расширить `features/catalog/` полем `unit` в форме добавления/редактирования товара.
- [ ] Добавить в навигацию CRM (`src/lib/config.ts`, `NAV_SECTIONS`) пункт "Портфолио" рядом с "Каталог".

### 4.3 Sync-скрипт (новый, в репозитории `vlmetal`)
- [ ] Node-скрипт `scripts/sync-content.js` (или Python, раз `sharp`/`exceljs` уже используются в проекте) — тянет `catalog` и `portfolio` из CRM API, генерирует:
  - секции прайс-листа (HTML-таблицы) для вставки в `metallokonstrukcii/index.html` и `otdelka/index.html`;
  - карточки для `/portfolio/index.html`.
- [ ] Скрипт скачивает и оптимизирует новые фото портфолио через `sharp` (webp + jpg fallback, соответствие правилу `ai/RULES.md` п.3).
- [ ] Обновляет `sitemap.xml` (`lastmod`) при изменении контента.
- [ ] Запуск — вручную командой перед деплоем (`node scripts/sync-content.js`), результат — обычные закоммиченные HTML/CSS/img файлы, которые уходят на GitHub Pages как обычно. Без гитхаб-экшенов/крона на первом этапе — по требованию можно добавить позже.
- [ ] Задокументировать процесс в `ai/RULES.md`: "как обновить прайс-лист/портфолио" → зайти в CRM, отредактировать → запустить sync-скрипт → закоммитить → запушить.
